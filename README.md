# Power BI Data Transformation & Modeling

This project includes two Power BI files focused on real-world data transformation and modeling.

## Contents
- **EmployeeDataModel.pbix**: 
  - Cleaned and reshaped multiple tables (e.g., employee, department, race).
  - Created calculated and conditional columns for financial and demographic metrics.
  - Built a normalized star schema model with resolved lookup values.
  - Ensured compatibility for analysis and reporting through optimized relationships.

- **SalesPivotUnpivot.pbix**:
  - Demonstrated unpivoting and pivoting transformations for sales data.
  - Renamed attributes and structured data for clean reporting.
  - Used Power Query for dynamic reshaping between wide and long formats.

## Tools & Techniques
- Power Query Editor
- Pivot/Unpivot columns
- Conditional columns and DAX
- Star schema modeling
- Relationship management
- Data cleaning and header promotion
